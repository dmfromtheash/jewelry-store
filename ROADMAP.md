# Roadmap

Current phase: Phase 1C - Document context hygiene, AI roles, and reference rules

## Phase 0: Project Memory

- Define product context.
- Create documentation baseline.
- Capture AI workflow and safety rules.

## Phase 1: GitHub / Repository Bootstrap

- Initialize Git repository.
- Create project documents and checklists.
- Make first local commit.
- Prepare GitHub repository when CLI/auth is available.
- Document context hygiene, AI handoff rules, AI role boundaries, and Makeup.ua product/UX reference rules.

## Phase 2: Stack and App Skeleton

- Choose the web stack.
- Create the app skeleton.
- Add basic local run instructions.

## Phase 3: Catalog and Product Data

- Define starter product data.
- Add categories and collections.
- Prepare product listing requirements.

## Phase 4: Product Detail Page

- Build PDP layout.
- Add variant, stock, care, and delivery sections.
- Add SEO-ready content structure.

## Phase 5: Wishlist and Cart

- Add wishlist behavior.
- Add cart behavior.
- Verify empty, filled, and disabled states.

## Phase 6: Checkout Demo

- Build a non-payment checkout demo.
- Add validation and success state.
- Keep real payments out of scope.

## Phase 7: Account / Order History

- Plan optional account and order history flows.
- Do not add real auth without a separate task.

## Phase 8: Admin

- Plan admin/product management.
- Do not add admin access without a separate task.

## Phase 9: SEO / Content

- Add metadata.
- Add structured data.
- Add category and product content.

## Phase 10: QA / Deploy

- Run smoke tests.
- Check accessibility, performance, and security baseline.
- Prepare deployment only after audit.
