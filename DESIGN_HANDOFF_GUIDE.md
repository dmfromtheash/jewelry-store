# Design Handoff Guide

## Future Handoff Needs

When design work starts, document:

- desktop screens;
- mobile screens;
- loading, empty, error, success, selected, disabled, and out-of-stock states;
- assets and image rules;
- spacing;
- typography;
- color tokens;
- component behavior.

## Priority

Design handoff should prioritize:

1. Layout clarity.
2. Product photo quality.
3. Mobile ergonomics.
4. Accessible color and type.
5. Consistent component states.
