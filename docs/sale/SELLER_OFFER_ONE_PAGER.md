# AURELIA — Что получает покупатель (One-Pager)

> Короткая, честная сводка предложения. Без преувеличений. **Не** утверждает
> наличия реальных платёжных/почтовых API, уведомлений, продакшн-хостинга или
> юридического соответствия. Подробности — в
> [`FEATURES_AND_LIMITS.md`](./FEATURES_AND_LIMITS.md).

## Что это

**AURELIA** — готовый, брендируемый интернет-магазин для **украинского** продавца
бижутерии / аксессуаров / подарков. Витрина + админка + сквозной поток заказа.
Валюта — **₴ (UAH)**. Стек: Next.js 15 / React 19 / Prisma / PostgreSQL.

Для кого: небольшой бренд, который сейчас принимает заказы вручную в директе и
хочет **настоящий сайт со структурой заказов**, а не переписку.

## Что уже работает

- Каталог на PostgreSQL: категории, товары, **варианты**, изображения и галерея.
- Витрина с реальным **селектором варианта** и ценой в ₴.
- **Гостевая корзина и оформление** с защитами (скрытые/распроданные позиции
  блокируются), инлайн-подтверждение заказа.
- **Серверно-авторитетная цена** (подделать цену с клиента нельзя).
- Админка: создание/редактирование товаров, публикация/скрытие, фото и галерея,
  **варианты**, **остатки**.
- **Заказы**: входящие, детальная карточка со снимком, жизненный цикл
  `submitted → processing → completed / cancelled`, **возврат остатка при отмене**,
  журнал действий.

## Стартовая модель (честно)

- **Оплата — ручная**: «оплата при получении» или «онлайн-оплата по реквизитам».
- **Доставка — ручная**: Самовывоз / Новая Почта / Укрпочта / Курьер + заметка.
- Это **сознательная** стартовая модель для Украины, а не недоделка.

## Что НЕ входит (отдельные платные этапы)

Реальный платёжный провайдер · API перевозчика и трекинг · email/SMS-уведомления ·
личный кабинет покупателя · отзывы · мультиязычность uk-UA/EN · продакшн-деплой ·
фискализация (РРО/ПРРО) и юридическое соответствие.

## Что входит в адаптацию под бренд

Название/логотип/тексты · реальный каталог и фото · контакты · доступ владельца
в админку. Полный список — [`SETUP_AND_HANDOFF_CHECKLIST.md`](./SETUP_AND_HANDOFF_CHECKLIST.md).

## Как посмотреть

10–15 минут по сценарию [`BUYER_DEMO_SCRIPT.md`](./BUYER_DEMO_SCRIPT.md):
витрина → товар → варианты → корзина → оформление → подтверждение → обработка
заказа в админке.

Скриншоты витрины (desktop + mobile) — в [`screenshots/`](./screenshots/);
