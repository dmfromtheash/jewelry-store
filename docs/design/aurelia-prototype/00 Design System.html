Принципы placeholders правило двух режимов

Админ видит зону загрузки: пунктирную рамку, круг с плюсом, действие («Добавить товар») и подсказку «Нажмите, чтобы загрузить изображение».

Покупатель видит спокойное состояние без служебного текста: знак-гемму и сообщение «Скоро будет добавлен товар» / «Скоро появится украшение». Переключатель режимов — в левом нижнем углу каждой страницы.
