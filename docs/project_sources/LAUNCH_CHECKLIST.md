# Launch Checklist

## Smoke Test Path

Before launch, verify:

1. Open home.
2. Go to catalog.
3. Use a filter.
4. Open a product.
5. Add to wishlist.
6. Add to cart.
7. Open checkout demo.
8. Trigger validation.
9. Complete demo flow.
10. Confirm success state.

## Launch Readiness

- SEO basics checked.
- Accessibility basics checked.
- Performance basics checked.
- Security basics checked.
- No real secrets committed.
- Real payment behavior audited before use.
