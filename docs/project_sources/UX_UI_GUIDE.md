# UX / UI Guide

## Required Pages

- home;
- catalog;
- category;
- product detail page;
- wishlist;
- cart;
- checkout demo;
- delivery;
- returns;
- care;
- about or brand story;
- contact.

## Required Components

- header and navigation;
- search;
- category menu;
- product card;
- filters;
- sort control;
- PDP gallery;
- variant selector;
- quantity control;
- add to cart;
- wishlist control;
- cart summary;
- checkout form;
- alert and validation messages.

## UX Requirements

- Mobile-first layout.
- Clear loading, empty, error, success, disabled, selected, and out-of-stock states.
- Product photo, name, price, stock, variants, add to cart, delivery/return, and reviews must have clear hierarchy.
- Forms must be easy to scan and correct.
