# Product Schema

Future product data should be structured and consistent.

## Core Fields

- `id`
- `slug`
- `sku`
- `name`
- `category`
- `collection`
- `price`
- `old_price`
- `currency`
- `stock_status`

## Jewelry Attributes

- `material`
- `coating`
- `metal_color`
- `stone_type`
- `sizes`
- `length`
- `weight`
- `care`

## Content Fields

- `short_description`
- `description`
- `images`
- `tags`
- `seo_title`
- `seo_description`

## Variants

Use variants for:

- ring size;
- chain length;
- metal color;
- stone type;
- set composition.
