# AI Workflow Guide

## Roles

- ChatGPT Project: strategy, requirements, product thinking, and task framing.
- Codex: repository audit, plans, focused code or documentation tasks, and safe Git work.
- Claude Code: local setup, diagnostics, running checks, debugging, and small fixes.

## Rule

One stage equals one report and one verification step.

## Good Task Shape

Each task should include:

- goal;
- scope;
- files allowed to change;
- expected checks;
- report format.
